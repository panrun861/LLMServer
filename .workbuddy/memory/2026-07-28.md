# 2026-07-28

## OpenHands Telegram Bot 架构重构

完成了 bot 从"内部 LLM 配置 + LiteLLM 同步"到"OpenHands profiles 驱动"的架构切换。

### 核心改动

**`core/openhands.py`:**
- `save_llm_profile()` 新增 `base_url`、`api_key`、`profile_name` 可选参数
- 新增 `get_llm_profile()` 方法获取单个 profile 详情
- `create_conversation()` 新增 `profile_model`/`profile_base_url` 参数（422修复：OpenHands要求agent.llm字段）
- `switch_conversation_profile()` 404 兼容处理

**`handlers/commands.py`:**
- `_sync_litellm_models()` → `_sync_openhands_profiles()` — 从 OpenHands `/api/profiles` 读取
- `_select_model_for_user()` 简化为直接激活 profile，不再创建
- `cmd_api_add` 改为直接写 OpenHands profile（不再写 LiteLLM）
- `cmd_api_delete` 改为删除 OpenHands profile
- `cmd_api_list/sync/switch` 全部切换到 OpenHands profiles
- callback_handler 中 `api_use:`、`api_del:`、`api_del_ok:` 全部适配
- StateStore: `dynamic_models` → `dynamic_profiles`，新增 `profile_model_map`
- 键盘按钮文字更新（"同步 LiteLLM" → "同步 OpenHands"）

### 部署
- `docker compose build --no-cache telegram-bot` ✅
- `docker compose up -d --force-recreate telegram-bot` ✅
- Bot 健康检查通过，Application started ✅
